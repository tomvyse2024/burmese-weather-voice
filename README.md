# မိုးလေဝသ — မြန်မာလိုပြောပြမယ်

တည်နေရာအလိုက် လက်ရှိရာသီဥတုနှင့် ၅ ရက်စာ ခန့်မှန်းချက်ကို ပြသပြီး မြန်မာလို အသံထွက်ဖတ်ပေးသည့် ရိုးရှင်းသော website ဖြစ်ပါတယ်။ HTML, CSS, JavaScript သာ အသုံးပြုထားပြီး API key မလိုပါ။

## ဖွင့်အသုံးပြုရန်

`index.html` ကို browser တွင်ဖွင့်ပါ။ တည်နေရာခွင့်ပြုချက်တောင်းလာလျှင် ခွင့်ပြုပေးပါ။ တည်နေရာမပေးလိုပါက မြို့အမည်ကို အင်္ဂလိပ်လို ရိုက်ရှာနိုင်ပါတယ်။

တည်နေရာရှာဖွေမှုကို browser အများစုက HTTPS သို့မဟုတ် localhost တွင်သာ ခွင့်ပြုသောကြောင့် website ကို GitHub Pages ကဲ့သို့ HTTPS hosting တွင်တင်ရန် အကြံပြုပါတယ်။

## အသံဖတ်ခြင်း

စာမျက်နှာဖွင့်ပြီး ရာသီဥတုအချက်အလက်ရလာသည်နှင့် မြန်မာလို အလိုအလျောက်ဖတ်ရန် ကြိုးစားပါတယ်။ Browser များ၏ autoplay ကန့်သတ်ချက်ကြောင့် အလိုအလျောက်အသံကို ပိတ်ထားနိုင်သည်။ ထိုအခါ **အသံဖြင့် ပြန်ပြောပါ** ခလုတ်ကို နှိပ်ပါ။ မြန်မာအသံထွက်အရည်အသွေးနှင့် ရရှိနိုင်မှုသည် အသုံးပြုသည့် browser နှင့် စက်ပေါ်မူတည်ပါတယ်။

## အသုံးပြုသော ဝန်ဆောင်မှုများ

- [Open-Meteo](https://open-meteo.com/) — ရာသီဥတုနှင့် မြို့ရှာဖွေမှု
- [BigDataCloud](https://www.bigdatacloud.com/) — တည်နေရာမှ မြို့အမည်ရှာဖွေမှု
- Browser Web Speech API — အသံဖတ်ခြင်း

## ဖိုင်များ

- `index.html` — စာမျက်နှာဖွဲ့စည်းပုံ
- `styles.css` — ဒီဇိုင်းနှင့် responsive layout
- `app.js` — တည်နေရာ၊ API၊ ခန့်မှန်းချက်နှင့် အသံဖတ်ခြင်း
